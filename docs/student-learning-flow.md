# Student Learning Flow

This document defines the learner journey used when updating the Digital Proficiency Kit, Learning Materials, and Teacher Toolkit. It is the editorial guide for making the three repositories feel like one course.

## Recommended course flow

### At the start of a module

The module landing page should answer, in student language:

1. What will I make or understand?
2. What do I need before I begin, and what tools/files do I need?
3. Which units do I complete, and in what order?
4. What will I hand in or be able to show at the end?
5. Where do I go if I get stuck?

The landing page should link directly to the student tutorial/workbook for each unit and to the runnable example and final task. Teacher plans and rubrics stay available in the teacher resources, but should not be required to figure out the student route.

### Within each unit

Use this sequence, adjusting the amount of practice to the topic:

1. **Goal and connection** — Say what the learner will know or make, why it matters, and how it connects to the previous unit.
2. **Get ready** — Name prerequisites, materials, starting file, and an accessible alternative if a tool is unavailable.
3. **See it** — Show a small finished example and ask the learner to predict what it does.
4. **Learn one idea** — Explain one new concept in plain language with a small annotated example.
5. **Try it with guidance** — Give short steps, expected results, and a checkpoint after each meaningful change.
6. **Practise and debug** — Offer a small variation and likely fixes for common errors.
7. **Make it yours** — Link the new skill to the module task, with a clear minimum version and optional extensions.
8. **Check and reflect** — Give a short completion checklist, evidence to save, and one or two reflection prompts.
9. **Look ahead** — Explain how the saved work or idea prepares the learner for the next unit.

### At the end of a module

The final task should combine skills already practised in the units. Label new challenges as optional extensions. State what to submit, how to check the result, and which rubric or feedback route applies. Include a short handoff to the next module.

## Roles of the three repositories

- **Digital Proficiency Kit:** student-facing module route, task briefs, and runnable examples.
- **Learning Materials:** detailed student tutorials and workbooks, plus classroom decks and teacher-annotated versions.
- **Teacher Toolkit:** lesson planning, differentiation, assessment rubrics, and teacher preparation.

Every student-facing landing page should tell learners which Learning Materials links to follow. A learner should not need to browse a repository tree to discover the next step.

## Unit quality checklist

- [ ] The module and unit order are consistent across all three repositories.
- [ ] The student goal and final evidence are stated near the beginning.
- [ ] Each new skill is introduced before a task depends on it.
- [ ] Steps include observable expected results or checkpoints.
- [ ] Required tools and files are distinguished from optional tools.
- [ ] The example, tutorial, workbook, and task links work and agree on scope.
- [ ] Accessibility and common recovery steps are part of the activity.
- [ ] Optional extensions are clearly marked as optional.
- [ ] The unit says what to save and how it leads into the next unit.

## Upgrade sequence

1. Pilot and refine this flow with Module 1 across all three repositories.
2. Reconcile the curriculum map and module/unit inventory with the actual materials.
3. Apply the student route and unit sequence to Modules 2–7, updating tutorials and workbooks where learning steps or practice are missing.
4. Review links, workload, task prerequisites, and progression across the full course.
