# Digital Proficiency Kit

Browser-based STEAM learning resources for building digital skills with HTML, CSS, and JavaScript.

Choose a route to get started:

- [Student learning modules](modules/README.md): learning units, tasks, and runnable examples.
- [Teacher lesson plans and rubrics](https://steam-c3t.github.io/teacher-toolkit/).
- [Slides, tutorials, and workbooks](https://steam-c3t.github.io/dpk-learning-materials/).

## Learning modules

1. [Introduction to the Web](modules/01-introduction-to-the-web/README.md)
2. [HTML Foundations](modules/02-html-foundations/README.md)
3. [CSS Styling & Layout](modules/03-css-styling-layout/README.md)
4. [JavaScript Essentials](modules/04-javascript-essentials/README.md)
5. [Data & Visualization](modules/05-data-visualization/README.md)
6. [Creative Web Projects](modules/06-creative-web-projects/README.md)
7. [Green STEAM Challenge](modules/07-green-steam-challenge/README.md)

Examples are interactive HTML files and can be opened directly from each module page. For the source files and version history, use the [GitHub repository](https://github.com/STEAM-C3T/digital-proficiency-kit).
