# Student Review Report: Digital Proficiency Kit

**Perspective:** Student learner  
**Scope:** Student-facing module pages, units, tasks, examples, and the learning path in this workspace  
**Purpose:** Record learner experience and improvement priorities for a later materials upgrade

## Overall impression

The kit has a promising course outline, useful examples, and a sensible broad progression from HTML to CSS, JavaScript, and larger creative projects. It gives accessibility meaningful attention and connects coding to engaging topics.

As a student working independently, I would find the early HTML and CSS activities fairly approachable. As the projects grow more complex, I would need more direct teaching, intermediate practice, and clearer directions. With a teacher guiding me, this feels like a useful course framework; on its own, it can feel more like a map of activities than a continuous course I can follow from start to finish.

## Strengths from a student perspective

- **The overall order makes sense.** I begin with HTML, add CSS, learn JavaScript, and then apply those skills in visualization, creative work, and a sustainability project.
- **The projects feel relevant and varied.** I can make a webpage, style a layout, create a chart, explore generative art, and build a small app.
- **Accessibility appears throughout the course.** Alt text, form labels, keyboard operation, contrast, and text alternatives for charts are part of the work.
- **The runnable HTML examples help me connect code to results.** Several module pages also provide concrete goals and reflection questions.
- **The Green STEAM project handles data and privacy thoughtfully.** It distinguishes a count of selected actions from a measurement of environmental impact and makes persistence optional.

## Friction points and gaps

### 1. Unit pages often tell me what to make, but not how to learn it

Many short unit pages read like teacher prompts or lesson outlines. They describe the activity, but don’t always explain the concept step by step, show what to try first, or help me check my understanding. For example, Unit 4.2 asks me to manage list state and render a todo list, but offers little explanation before pointing me to the example.

### 2. The learning path is spread across repositories

The kit points to separate Learning Materials and Teacher Toolkit repositories. As a student, I may not know which resource to open first, which materials are essential, or how they fit together. The module pages work well as directories, but less well as a single continuous student course.

### 3. Some tasks expect skills that haven’t been clearly taught yet

The first task asks for semantic structure, heading hierarchy, links, lists, and an image with alt text, while the listed unit activities don’t explicitly walk through every part. In later modules, several new concepts arrive together: Canvas, scaling, axes, and accessible tables in Module 5; animation and controls in Module 6; and planning, coding, peer feedback, and impact claims in Module 7. I would benefit from more small, guided practice before these larger tasks.

### 4. Some course materials don’t appear to agree

The curriculum map lists a Unit 5.2, but Module 5 currently presents only Unit 5.1. The map also mentions topics such as JSON and external data that aren’t clearly part of the student-facing sequence. Module 1 has duplicate unit files at the module root as well as in the `units/` folder, which makes it harder to know which copy to follow.

## Recommendations for the next upgrade

1. **Make the student route explicit.** For every unit, show me where to start, what to read or open next, and which materials are required versus optional.
2. **Teach concepts in small steps.** Add concise explanations, annotated examples, and small code changes I can try before asking me to build a whole feature.
3. **Add checks for understanding.** Include short prediction, “change this and observe,” or debugging activities so I can tell whether I understand each new idea.
4. **Build a bridge from examples to tasks.** Make each task’s prerequisites clear and provide intermediate exercises for skills that haven’t yet been practised.
5. **Reconcile the course references.** Align the curriculum map, module pages, units, and linked repositories; resolve missing or duplicate unit references.
6. **Keep the existing strengths.** Preserve the creative project choices, browser-based examples, accessibility focus, and thoughtful treatment of sustainability data and privacy.

## Student conclusion

I’d be interested in learning with this kit, especially with a teacher available to guide me. To feel confident learning independently, I need a clearer path and more step-by-step teaching as the work gets harder. I’d most like the course to connect each lesson directly to its practice and project, so I can see what I’m learning, try it safely, and then use it in my own work.
