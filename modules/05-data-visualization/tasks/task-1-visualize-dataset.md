# Task: Visualize a Small Dataset

## What you will make

Create a Canvas bar chart for a small dataset. Use the chart and scaling steps in Unit 5.1 as your model. Keep the data small enough that you can check every value against its bar.

## Steps

1. Choose 4–8 numeric values. Write down what each value measures, its label, and its unit.
2. Start from the [Canvas bar chart example](../examples/canvas-bar-chart.html) or the Unit 5.1 starter code. Replace the example values and labels with your own.
3. Use a consistent scale to map each value to a bar height. Check at least the smallest and largest values.
4. Add a chart title, value labels, and units. Avoid overlapping labels.
5. Add an HTML table with a caption and header cells so the data is available as text.
6. Open the page in a browser and compare each table value with its bar and label.
7. Write a short reflection about why the chart helps and one way its scale or labels could mislead.

## Design goals

- Represent 4–8 numeric values as bars using `<canvas>`.
- Provide a title, readable labels, units, and value annotations.
- Pair the chart with an HTML data table.

## Check your work

- Data is stored as an array or object in JS; no external libraries.
- Bar heights map values consistently, including the smallest and largest values.
- Chart title, units, labels, and value annotations match the data.
- The companion table has a caption and headers and lists the same values.
- The chart remains understandable without colour alone.

## What to submit

- One HTML file containing your chart and companion table.
- A 2–3 sentence reflection: Why this chart? How does it help interpret the data, and what limitation should a reader know?
