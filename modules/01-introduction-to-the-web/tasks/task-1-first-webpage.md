# Task: Your First Webpage

## What you will make

Create a small page about a topic you choose. You can use the page you started in Unit 1.2. Your page should help a visitor understand the topic and move around its content.

## Steps

1. Start from your saved Unit 1.2 page or copy [`../examples/minimal-page.html`](../examples/minimal-page.html) into your project folder.
2. Add a clear page title and one main heading. Use a subheading if your page has another section.
3. Add a short paragraph and a list of at least two related items.
4. Add one useful link with descriptive words that make sense out of context.
5. Add an image. Write alt text that describes the useful information in the image; if the image is only decoration, use empty alt text (`alt=""`).
6. Open the file in a browser. Check the page title, image, and link, then use Tab to move through links and confirm focus is visible.
7. Save the file and write a brief reflection on one structure or accessibility choice.

## Design goals

- Create a semantic page with `<header>`, `<main>`, and `<footer>`.
- Include a page title, a main heading, a paragraph, a list, a descriptive link, and an image with appropriate `alt` text.

## Check your work

- Valid HTML5 structure with `<!DOCTYPE html>` and `lang` attribute.
- Uses semantic tags and a logical heading order.
- Link text describes its destination; image alternative is appropriate to the image's purpose.
- Page readable on mobile (no horizontal scroll at 320px).
- Opens in a browser, with working links and a visible keyboard focus indicator.

## What to submit

- One HTML file and a 1–2 sentence reflection explaining one structure or accessibility choice.
