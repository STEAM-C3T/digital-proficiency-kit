# Task: Build an Accessible Survey Page

## What you will make

Extend the content page from Unit 2.1 with a short survey form and a table of sample results. This is a static practice page: it does not send or save responses. Use fictional names and answers only; do not enter personal or sensitive information.

## Steps

1. Open your saved content page or copy [`../examples/student-survey.html`](../examples/student-survey.html) into your project folder.
2. Add a survey section with two or three questions. Give every form control a visible `<label>` connected to its `id`.
3. Add a submit button. For this practice page, explain near the form that responses are not collected or saved.
4. Add a results section with a table of fictional sample responses. Use `<th>` for column headings and add a `<caption>` that describes the table.
5. Open the page in a browser. Use Tab to move through the form and check that each control has a visible label and focus indicator.
6. Save the file and write one sentence explaining how a label or table header helps a visitor.

## Check your work

- The page keeps the heading, list, link, and image from the content-page practice.
- Each form control has a visible, associated label.
- The form has a submit button and clearly says that this static page does not collect responses.
- The table has a caption and header cells that describe the columns.
- No real personal or sensitive data appears in the page.

## What to submit

One HTML file and a one-sentence reflection. The form is for practising accessible markup; it does not need JavaScript or a server.
