# Task: Build a Content Page

## What you will make

Create a short page about a topic you know. Build it in small pieces and check each piece in your browser.

## Steps

1. Create an HTML file with `<!doctype html>`, `<html lang="en">`, a `<head>` with a page `<title>`, and a `<body>`.
2. Add a `<header>` with one `<h1>` that names your topic, a `<main>` for its content, and a `<footer>` for a short closing note.
3. Inside `<main>`, add one `<h2>` and a short paragraph. Open the page and confirm the title and heading appear.
4. Add a list with at least two related items. Refresh the browser and check that the list is clear.
5. Add a link whose words explain where it leads. Add `rel="noopener"` if you choose to open it in a new tab.
6. Add an image in a `<figure>`. Write `alt` text that conveys useful information; use `alt=""` if the image is decorative. Add a `<figcaption>` if it helps explain the image.
7. Check the heading order, link text, and image alternative. Save the file and write one sentence about an accessibility choice you made.

Design goals:

- Create a small topic page with headings, paragraph, list, image, and a link.
- Use semantic tags where possible and provide alt text for images.

Acceptance criteria:

- Has `<h1>` and at least one `<h2>`; contains a list (`<ul>` or `<ol>`).
- Includes a figure with an `<img>` and descriptive `alt` text.
- External link uses `rel="noopener"` when `target="_blank"`.

Deliverable:

- One HTML file with minimal, clean structure.
